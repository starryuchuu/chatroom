# 聊天区 UI 调整与验证

本记录描述聊天区调整完成时的验证；后续草稿、待确认列表与时区改动见[后续验证](DRAFTS_SENDS_TIME_VALIDATION.md)。本记录对应尚未发布的开发分支，承接[发送恢复、缓存与搜索](../SEND_RECOVERY_AND_CACHE.md)。本轮调整聊天操作、消息排版和搜索体验，沿用现有收发、加密及缓存行为。

## 交互变化

- 顶部保留“搜索”和“更多”。历史加载和群聊信息进入菜单，菜单按会话、连接、加载及耗尽状态更新。返回最新消息统一留在聊天区底部。
- `message_rows.py` 负责日期分隔、五分钟内同作者且同安全状态消息的分组、正文与元信息排版。每个显示窗口开头补足日期与作者上下文，窗口仍最多保留 120 行。
- 时间简写为时分，安全标记缩短；点击元信息可在消息下展开完整时间和安全说明。旧消息与验证失败保持明确标识。正文使用较大的独立字体，阅读锚点由消息行顶部改为正文位置。
- 搜索范围与结果位置持续可见，导航按钮使用“上一个 / 下一个”，无结果时禁用。关闭或 Esc 在原消息仍在缓存时恢复原阅读位置，原本跟随最新时继续跟随。位置快照只保留会话、消息身份与像素偏移，不额外保留正文。
- 高亮按视口宽度调整，当前匹配在深浅主题下的实际文字与背景对比度均通过至少 4.5:1 的检查。

## 回归覆盖

新增 12 项真实 Tk 回归，覆盖菜单键盘打开及权限状态、日期 / 作者 / 时间间隔 / 安全状态边界、原位完整信息、解密恢复后的相邻分组与控件复用、跨显示窗口的正文锚点、唯一的底部返回入口、清除选择，以及搜索返回位置、实时跟随、对比度、缩放与空结果导航。

缩放高亮与尚未执行的滚动回调交错时，定向用例复现了渲染重入、访问已销毁文本控件的问题。缩放现在先处理已有滚动状态；展开消息信息也先取消旧滚动，再捕获完整视口。相关回归与界面定向检查共 79 项通过。

最终本地完整回归：557 项 Python / 真实 Tk / Python-Go 互操作测试全部通过，无跳过，耗时 302.160 秒；未出现 Tk 回调异常。Linux 客户端实际 PyInstaller 构建成功，确认包含 `message_rows.py`，并通过加密运行时自检。源码与客户端成品通过发布隐私检查。此前发送恢复功能的服务端验证继续见其独立记录。

## 合成渲染测量

同一云端 Linux / Xvfb 环境运行 `scripts/benchmark_client_render.py --messages 2000 10000`：

| 依次插入消息数 | 保留缓存条数 | 显示行数 | 首次渲染 | 不变内容重绘 | 复用行数 |
| --- | --- | --- | --- | --- | --- |
| 2,000 | 2,000 | 120 | 371.636 ms | 10.517 ms | 120 |
| 10,000 | 2,000 | 120 | 354.983 ms | 11.535 ms | 120 |

日期、作者和元信息控件增加了首帧开销，后续重绘继续复用已有行。这是合成短消息的一次参考测量，运行时还存在其他本地验证任务，不作为跨平台性能阈值。缓存上限不代表整个进程内存上限；Python 分配测量也不包含 Tcl/Tk 原生内存。

## 验证边界

本轮未推送或触发远端 CI，未执行 Windows 成品测试。云端 Tk 没有可用的 CJK 字体，中文实际字形与原生桌面外观仍需桌面平台复核；本地检查覆盖控件布局、状态、内容、事件和滚动。版本号保持 v1.4.0，本轮不提交或发布新版本。
