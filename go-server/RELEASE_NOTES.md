# v1.0.11 — AES-256-GCM 存储加密

与 Python 服务端共用存储 v1，保护聊天正文和敏感字段，采用独立密钥及 HMAC 用户名索引。启动时事务迁移旧数据并清理旧页；错误密钥或密文验证失败时拒绝继续操作。

网络协议 v2 不变，兼容 v1.0.10 客户端。必须单独备份对应的 `chat.db.key`；禁止将迁移后的数据库交给旧服务端打开。详情见根目录 [发布说明](../RELEASE_NOTES.md) 和 [存储说明](../STORAGE_ENCRYPTION.md)。

验证：Windows / Linux 各 70 项 Python / Tk / Go 互操作测试通过，Go 静态检查、回归及 Linux 数据竞争检测通过；包含迁移回滚、密钥恢复、明文残留扫描、篡改拒绝和跨语言数据库兼容测试。
