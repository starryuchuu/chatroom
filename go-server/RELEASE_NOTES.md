# v1.0.15 — 保留服务器身份与私钥权限修复

修复私钥丢失但公钥仍存在时静默替换 RSA 身份的问题：现在停止启动、保留原公钥并提示恢复原私钥。恢复后客户端固定的原公钥指纹仍然有效。POSIX 系统上已有私钥权限会收紧至 `0600`，新私钥以该权限独占创建，避免覆盖其他进程已创建的私钥。

新增真实进程可靠性测试，验证并发收发、强制终止后历史恢复、离线申请恢复、连接回收、SQLite 写入失败后重试、TCP 分片及非法报文隔离。两端分别通过 8 客户端 1,200 条及 32 客户端 1,120 条消息核对；详见[可靠性验证记录](../RELIABILITY_VALIDATION.md)。

网络协议 v2、存储格式 v1 不变，兼容 v1.0.10 至 v1.0.14 客户端。升级前停止旧服务端并备份数据库及对应的 `chat.db.key` 和 RSA 私钥。完整下载及升级说明见根目录[发布说明](../RELEASE_NOTES.md)。
