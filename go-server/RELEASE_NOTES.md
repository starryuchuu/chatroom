# v1.0.10 — 协议 v2 与可靠历史同步

- 完整报文认证及防重放，拒绝旧协议和明文登录。
- 修复群历史权限同步、登录快照竞态及大快照分包；入群后立即补发历史。
- 历史按消息 ID 分页，每页最多 100 条，并自动建立查询索引。
- 好友申请和群邀请写入 SQLite，重启后恢复；接受申请与更新关系在同一事务中完成。
- 同 IP 认证失败限流，限制并发认证及总连接数。
- 单个 SQLite 连接配合繁忙等待时间，修复并发登录与申请保存时偶发的数据库锁冲突。

必须配套 v1.0.10 Python 客户端，不兼容 v1.0.9 及更早版本。保留原有数据库和服务端密钥；新表和索引自动建立。默认端口为 `12346`，提供 Windows、Linux、macOS 的 amd64 / arm64 二进制。

Go 静态检查、回归与数据竞争检测，以及 Windows / Linux Python 客户端互操作测试通过。详细升级说明见根目录 [发布说明](../RELEASE_NOTES.md) 和 [协议说明](PROTOCOL_COMPATIBILITY.md)。
