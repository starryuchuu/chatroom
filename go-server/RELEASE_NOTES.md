# v1.0.8 — Go 服务端协议适配

本次与 Python 客户端、Python 服务端一起发布，完整下载与说明见仓库根目录 [发布说明](../RELEASE_NOTES.md)。

- 消息提交后确认，成功与失败响应关联 `request_id`，实时与历史消息携带 `message_id`。
- 历史同步开始/结束、统一 ID 边界与全局排序，兼容旧数据库 NULL 列。
- 登录后每连接发送队列与 5 秒超时，群操作不等待网络写入，历史使用有界回压。
- 拒绝邀请会消费邀请；群管理结果避免操作者重复通知，改名返回旧名称。
- Go 单元测试、静态检查、数据竞争检测和 5 项真实 Python/Go 互操作测试通过。

默认监听 `127.0.0.1:12346`，适配 v1.0.7 / v1.0.8 Python 客户端。无需迁移数据库。支持 Windows、Linux、macOS 的 amd64 / arm64。
