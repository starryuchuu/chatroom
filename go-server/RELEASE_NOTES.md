# v1.0.12 — 群组并发与好友快照修复

- 修复建群与登录群列表快照并发时重复获取 catalog 读锁造成的死锁。
- 将最新好友快照的读取、入队与会话发布按接受好友申请的提交顺序协调，避免丢失新增好友。
- 创建群与改名统一限制为 1 至 128 个 Unicode 字符，拒绝纯空白名称；截断历史长群名在改名通知中的旧名称，避免结果报文超限。
- 增加确定性并发、好友快照与群名边界回归测试，并运行 Go 静态检查和数据竞争检测。

网络协议 v2、存储格式 v1 不变，兼容 v1.0.10 / v1.0.11 客户端。升级前停止旧服务端并备份数据库及对应的 `chat.db.key` 和 RSA 私钥。详情见根目录[发布说明](../RELEASE_NOTES.md)。
