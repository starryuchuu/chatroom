# v1.0.6 — Go 服务端稳定性与并发修复

本次发布 Go 服务端，兼容 v1.0.5 Python 客户端；默认监听 `127.0.0.1:12346`。客户端端口选择为 `12346` 即可连接。

## 修复

- 消息长度检查在内存分配之前执行，并统一为与 Python 客户端相同的 1 MiB 上限；拒绝空帧和畸形 JSON。
- 同一连接的完整消息帧串行发送，正确处理短写；每次发送刷新写入截止时间，修复连接建立 30 秒后无法发送的问题。
- 认证失败始终返回错误，拒绝无效 AES 会话密钥，避免空用户名会话。
- 登录先原子保留用户名、发送成功响应，再开放广播和消息投递；重复登录的失败连接不会移除原在线用户。
- 广播使用在线连接快照，在发送期间释放客户端管理器锁，避免慢连接阻塞登录和离线清理。
- 同一群组的加入、退出、踢人、邀请、转让、重命名、解散、信息查询和聊天按顺序执行，防止成员更新丢失及群主退出竞态；不同群组可并行操作。
- 创建群聊仅允许加入好友，校验成员列表并去重。
- 离线好友申请及群组邀请保存后返回成功，上线后补发；请求有效期 24 小时，已处理或解散群组的记录及时清理。
- 好友关系持久化成功后才通知接受结果；数据库失败时保留申请以便重试。
- 用户名和密码长度按 Unicode 字符数校验，兼容中文输入。
- 公钥文件缺失、损坏或不匹配时从现有私钥修复，保留服务器身份；认证超时 30 秒，登录后空闲超时 30 分钟。

## 验证与下载

- 28 项 Go 顶层回归测试（含子测试）、`go vet` 和 Linux `go test -race`。
- Windows 与 Linux 使用真实 Python 客户端协议运行 2 项互通测试，覆盖加密注册和登录、错误密码、重复登录、离线好友申请、私聊、群聊及群组生命周期；实际等待 31 秒验证写入截止时间更新。
- Windows、Linux、macOS 的 amd64 与 arm64 共 6 个 Go 服务端程序，源码 ZIP 和 SHA256SUMS 校验文件。

Windows 下载对应架构的 `.exe` 后直接运行；Linux/macOS 下载对应架构文件后执行 `chmod +x`，再运行。运行目录会生成数据库及 RSA 密钥文件。

待处理的好友申请和群组邀请保存在内存中，服务器重启后需重新发送。macOS 与 arm64 构建经过交叉编译，未进行各设备上的人工运行验收。
