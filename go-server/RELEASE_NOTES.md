# v1.2.0 — 端到端密文与公开身份验证

- 握手声明 `e2ee_v1` 能力，保存不可静默替换的端到端公开身份；验证 Ed25519 签名、发送者、接收人及当前群成员，原样转发、存储和分页补取密文。
- 已登记加密身份的账号拒绝明文聊天路径；配套新版客户端在本机完成私聊、群聊加密，支持独立口令密钥库、指纹核对与加密备份恢复。
- 传输协议 v2、存储加密 v1 保留，新增公钥表和消息加密标志。请先备份数据库及存储密钥；升级后的数据库不要再交给旧服务端运行。
- Windows / Linux 回归及 Linux 竞争检测覆盖加密互操作、历史补取、身份替换与明文降级，验证同一数据库在 Python / Go 之间双向迁移；配套客户端成品增加加密运行时自检。

请先升级服务端再升级客户端。首次信任需独立核对指纹，旧历史不会追溯加密，本协议不提供长期接收私钥后来泄露后的前向保密。完整功能、密钥备份和保护范围见[发布说明](../RELEASE_NOTES.md)与[端到端加密文档](../docs/END_TO_END_ENCRYPTION.md)。

# v1.1.0 — 断线增量同步与配套客户端功能

- 握手声明 `message_sync` 能力，支持 `sync_request` 在固定消息边界内前向分页补取全部遗漏消息，每页最多 100 条，超过一页的断线消息也可恢复。
- 每页只返回当前有权读取的私聊与群消息，群消息排队前再次校验成员资格；开始和完成事件关联请求 ID、起点与边界，失败不会确认已完成。
- 历史消息携带可选回放标记，防止客户端将历史补取误报为实时桌面提醒。新消息预留回放元数据空间；旧版近报文上限的记录保留正文及 ID，必要时省略可选标记。
- 配套 Python 客户端增加服务器配置、未读/最近消息、桌面提醒与免打扰、可取消的自动重连。配置不保存密码或正文。

帧协议 v2 和存储格式 v1 不变，无需数据库迁移；兼容 v1.0.10–v1.0.17 客户端。完整自动补取需使用 v1.1.0 客户端及服务端。详情见[完整发布说明](../RELEASE_NOTES.md)与[协议说明](PROTOCOL_COMPATIBILITY.md)。
